# SVG Images for IELTS Writing Task 1

This directory contains 8 sample IELTS Task 1 writing images in SVG format.

## Image Files

1. **line-graph-shopping.svg** - Line graph showing online shopping adoption rates in 4 countries (2005-2020)
2. **bar-chart-energy.svg** - Bar chart comparing global energy consumption by source
3. **pie-chart-devices.svg** - Pie chart showing device usage distribution
4. **table-education.svg** - Table showing education enrollment rates by level
5. **process-diagram-water.svg** - Process diagram showing water treatment steps
6. **map-tourism.svg** - Map showing major tourist destinations
7. **column-chart-sales.svg** - Column chart showing quarterly sales trends (2021-2023)
8. **area-chart-traffic.svg** - Area chart showing website traffic patterns by device type

## Features

- All images are in SVG format (500x300px)
- Clean, IELTS-style design with grayscale color scheme
- Includes axis labels, legends, and titles
- Ready for use as writing practice prompts
- Can be displayed directly in HTML or converted to PNG

## How to Create These Files

Run the setup script:

```bash
node setup-images.js
```

Or on Windows:

```cmd
setup-images.bat
```

This will create all 8 SVG files in this directory.
